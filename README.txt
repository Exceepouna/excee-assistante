EXCÉE ASSISTANTE — prototype PWA
1) Décompressez le dossier.
2) Pour tester localement, ouvrez index.html dans un navigateur récent.
3) Pour l'installer sur iPhone, hébergez les fichiers sur un site HTTPS (par exemple GitHub Pages).
4) Sur iPhone : ouvrez l'URL dans Safari > Partager > Ajouter à l'écran d'accueil.
Limites de cette version :
- interface de démonstration, sans modèle IA connecté ;
- aucun appel, SMS ou message WhatsApp réel ;
- dictée vocale dépend du navigateur et de la langue prise en charge ;
- le Lingala est proposé pour la saisie, mais la reconnaissance vocale n'est pas garantie.
Ne placez aucune clé API secrète dans index.html.
